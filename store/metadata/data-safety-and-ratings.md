# 데이터 안전 · App Privacy · 콘텐츠 등급 답변지

> 기준일: 2026-08-28. 이 문서는 현재 저장소의 API 스키마와 Expo 의존성을 기준으로 한 제출 초안입니다. 스토어 콘솔 제출 직전에 프로덕션 빌드, SDK Privacy Report, 서버 로그 필드를 다시 대조해야 합니다.

## 실제 처리 항목 요약

- 계정: 이메일, 비밀번호의 솔트·단방향 해시, 사용자 ID, 표시명(별칭)
- 그룹: 그룹 ID·이름·설명·관리자·가입 상태·관리자가 정한 출타 상한
- 휴가: 제목, 날짜, 선택 사유, 휴가 분류·잔여량·부여일·만기·선택 메모
- 친구: 친구 요청·수락 상태, 관계 사용자 ID와 시각
- 개인 일정: 제목, 날짜, 선택 로컬 시간·메모(소유자 전용)
- 알림: 선택적 Expo 푸시 토큰, 인앱 알림, 이 앱 푸시의 발송·수신·열람 기록
- 자동 로그: 사용자 ID(로그인 시), 요청 시각·메서드·경로·상태, 플랫폼·앱 버전, 응답 시간
- SDK: Expo Insights가 앱 콜드 스타트와 업데이트 사용량을 측정할 수 있음. Sentry가 오류·충돌 발생 시 내부 사용자 ID, 예외·기호화용 스택, 화면/요청 경로 템플릿, 요청 상태·시간·요청 ID, 앱·빌드·OS·런타임·업데이트 식별자와 앱/네트워크 상태를 처리함. 본문·토큰·연락처·도메인 데이터·IP 이벤트 저장·화면 캡처·세션 리플레이는 제외함

비밀번호 원문은 서버에서 즉시 솔트·해시로 변환하고 원문을 저장하지 않습니다. 앱은 사진·위치·연락처·카메라·마이크 데이터를 수집하지 않습니다.

## Google Play Data Safety

### 상위 답변

| 질문           | 답변                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------ |
| 데이터 수집    | 예                                                                                         |
| 제3자 공유     | 아니요 — Cloudflare, Expo, APNs, FCM은 서비스 제공을 위한 처리업체이며 판매·광고 공유 없음 |
| 전송 중 암호화 | 예 — HTTPS/TLS                                                                             |
| 삭제 요청      | 예 — 앱 내 삭제 + 공개 웹 안내                                                             |
| 광고           | 없음                                                                                       |
| 독립 보안 검토 | 아니요                                                                                     |

### 데이터 유형

| Play 데이터 유형                  | 수집 |   공유 | 필수/선택                     | 목적                      |
| --------------------------------- | ---: | -----: | ----------------------------- | ------------------------- |
| 개인정보 > 이름                   |   예 | 아니요 | 필수 입력이나 별칭 권장       | 앱 기능, 계정 관리        |
| 개인정보 > 이메일 주소            |   예 | 아니요 | 필수                          | 계정 관리, 보안           |

| 앱 활동 > 앱 상호작용             |   예 | 아니요 | 자동                          | 분석, 앱 기능, 보안       |
| 앱 활동 > 기타 사용자 제작 콘텐츠 |   예 | 아니요 | 일정은 필수, 사유·메모는 선택 | 그룹 일정 공유, 휴가 관리 |

모든 항목은 계정 또는 그룹과 연결될 수 있습니다. 광고, 교차 앱 추적, 데이터 브로커 제공에는 사용하지 않습니다.

### 계정 삭제

- 인앱: 프로필 → 계정 삭제 → `DELETE /auth/account`
- 웹 안내: `https://leave.moveto.kr/delete-account`
- 삭제 대상: 사용자, 세션, 가입 요청·초대코드, 친구 요청·관계, 개인 일정, 휴가와 하위 데이터, 휴가 잔여/부여 설정, 알림, 접속·푸시 로그. 관리자였던 1인 그룹은 그룹을 삭제하고, 구성원이 남으면 관리자를 승계합니다.
- 배포 직전 프로덕션 환경에서 생성→삭제→재로그인 실패→DB/로그/백업 보존 정책 확인을 다시 수행해야 합니다.

## 권한 신고

- 요청하지 않음/차단: 카메라, 마이크, 위치, 연락처, 사진·미디어/외부 저장소
- 앱 기능상 사용: 알림 런타임 권한(Android 13+), 네트워크, 알림 전달에 필요한 진동/부팅 수신 권한

## 콘텐츠 등급과 UGC

표시명, 그룹 이름·설명과 집계 대상 휴가 날짜·상태가 같은 그룹 구성원에게 보이고, 수락한 친구끼리 최소한의 휴가 날짜·상태를 공유할 수 있으므로 두 스토어 모두 사용자 생성 콘텐츠와 사용자 간 상호작용을 `예`로 신고합니다. 휴가 제목·사유와 개인 일정은 친구에게 노출되지 않습니다. 자유 채팅이나 공개 피드는 없고, 위치 공유와 결제는 없습니다.

연령 등급 숫자를 문서에서 임의로 고정하지 말고 최신 콘솔 설문 결과를 사용합니다. 대상 연령은 만 18세 이상이며 아동 대상 앱이 아닙니다.

### 출시 차단

현재 앱에 UGC 인앱 신고·사용자 차단·운영자 검토 흐름이 없다면 Apple 1.2와 Google Play UGC 정책을 충족했다고 볼 수 없습니다. “폐쇄형 그룹이라 위험이 낮다”는 이유로 생략하지 말고 구현·운영 절차·연락처를 갖춘 뒤 제출합니다.
