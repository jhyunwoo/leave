## ⚠️ 제출 전 필수 확인 — 계정 삭제 기능
**Apple(가이드라인 5.1.1(v))과 Google Play 모두, 계정을 생성하는 앱은 "앱 내 계정 삭제" 또는 "삭제 요청 경로"를 제공해야 합니다.** 현재 앱에는 계정 삭제 기능이 없습니다. 아래 중 하나가 필요합니다.
1. (권장) 앱에 계정 삭제 기능 추가 — 프로필 화면에 "계정 삭제" → 서버 `DELETE /auth/account`로 사용자·세션·휴가·로그·프로필 이미지 삭제.
2. (임시) 데이터 삭제 요청 URL/이메일 제공: `jhyunwoo0228@gmail.com` 로 요청 시 처리 — 두 스토어의 "데이터 삭제 요청 방법"에 기입.
> 원하시면 1번(계정 삭제 API + 프로필 UI)을 구현해 드리겠습니다.

## 🟢 Google Play — 데이터 안전(Data safety) 양식 답변

**데이터를 수집/공유하나요?** 예(수집). **제3자와 공유?** 아니요(서비스 제공업체 Cloudflare/Expo/APNs/FCM는 위탁 처리이며 판매·광고 목적 공유 없음). **전송 중 암호화?** 예(HTTPS/TLS). **삭제 요청 방법 제공?** 예(위 참조).

| 데이터 유형 | 카테고리 | 수집 | 공유 | 필수/선택 | 목적 |
|---|---|---|---|---|---|
| 이름 | 개인정보 > 이름 | ✔ | 아니요 | 필수 | 앱 기능(부대원 식별) |
| 이메일 | 개인정보 > 이메일 주소 | ✔ | 아니요 | 필수 | 계정 관리 |
| 군 복무 정보(군종·계급·입대/전역일) | 개인정보 > 기타 정보 | ✔ | 아니요 | 필수 | 앱 기능(계급 자동 계산) |
| 프로필 사진 | 사진 및 동영상 > 사진 | ✔ | 아니요 | 선택 | 앱 기능(프로필) |
| 휴가 제목·사유 | 앱 활동 > 기타 사용자 생성 콘텐츠 | ✔ | 아니요 | 선택(사유는 선택) | 앱 기능(부대 내 공유) |
| 앱 상호작용(접속 기록) | 앱 활동 > 앱 상호작용 | ✔ | 아니요 | 필수 | 분석, 앱 기능, 사기 방지/보안 |
| 기기 식별자(Expo 푸시 토큰) | 기기 또는 기타 ID | ✔ | 아니요 | 필수 | 앱 기능(푸시 알림) |
| 대략적 위치(IP 기반 국가) | 위치 > 대략적인 위치 | ✔ | 아니요 | 필수 | 사기 방지/보안 |
| 진단(응답 시간 등 성능) | 앱 정보 및 성능 > 진단 | ✔ | 아니요 | 선택 | 분석 |

> 참고: 비밀번호는 원문 저장 안 함(솔트+해시). 위 표에 "비밀번호"는 별도 데이터 유형으로 신고하지 않습니다(계정 인증용).

## 🍎 App Store — App Privacy(개인정보 보호) 라벨

**"데이터 추적(Tracking)"에 사용?** 아니요(광고 추적/데이터 브로커 공유 없음) → App Tracking Transparency 불필요.
아래는 모두 **"사용자에게 연결됨(Linked to You)"**, 목적은 **앱 기능 / 분석**.

| App Store 데이터 유형 | 항목 | 목적 |
|---|---|---|
| Contact Info | 이메일, 이름 | App Functionality |
| User Content | 사진(프로필), 기타(휴가 제목·사유) | App Functionality |
| Identifiers | 사용자 ID, 기기 ID(푸시 토큰) | App Functionality |
| Usage Data | 제품 상호작용(접속 기록) | Analytics, App Functionality |
| Diagnostics | 성능 데이터(응답 시간) | Analytics |
| Location | 대략적 위치(국가) | App Functionality, (보안) |

- Data Used to Track You: **없음**
- Data Linked to You: 위 전 항목
- Data Not Linked to You: 없음

## 🎯 콘텐츠 등급

### App Store 연령 등급 → **4+**
새 연령 등급 설문 답변:
- 폭력/성적 콘텐츠/비속어/약물/도박/공포 등: 전부 **없음**
- 제한 없는 웹 접근: **아니요**
- 사용자 생성 콘텐츠(UGC): **예 (제한적)** — 휴가 제목·사유가 같은 부대원에게만 공개. 자유 채팅/공개 게시판 없음. 신고/차단 등 모더레이션이 필요할 수 있으니 심사 노트에 "부대 내 소규모 일정 공유"임을 명시.
- 결과 등급: **4+** 예상

### Google Play 콘텐츠 등급(IARC 설문) → **전체이용가**
- 폭력/성/욕설/약물/도박: 전부 **아니요**
- 사용자 간 상호작용/콘텐츠 교환: **예** — 같은 부대원끼리 휴가 일정(텍스트) 공유. 공개 커뮤니케이션·실시간 위치 공유 **없음**.
- 사용자의 정확한 위치를 다른 사용자와 공유: **아니요**
- 디지털 상거래/구매: **아니요**
- 결과: **전체이용가(Everyone)** + "사용자 간 상호작용" 표시 가능

> ⚠️ UGC가 있으므로, 향후 신고/차단 기능이 없으면 일부 시장에서 보완 요청이 올 수 있습니다. 부대(폐쇄형 소규모) 특성상 리스크는 낮습니다.
