# ASO 키워드 원칙

리브는 군 공식 서비스로 오인될 수 있는 키워드 확장보다 기능을 정확히 설명하는 표현을 우선합니다. 앱 이름, 설명, 스크린샷 어디에도 국방부·각 군·부대 마크·공식 로고를 사용하지 않습니다.

## 권장 의도

| 의도 | 권장 표현 |
|---|---|
| 핵심 기능 | 휴가 일정, 휴가 캘린더, 일정 공유, 그룹 캘린더 |
| 계산 결과 | 출타율, 혼잡도, 여유, 임박, 계획 참고 |
| 개인 계획 | 휴가 계획, 재원별 잔여, 적립분, 만기 관리 |
| 군별 기능 | 공군 정기외박, 해군 정기외박, 주기별 적립 |

## 피할 표현

- 공식, 승인, 예약 확정, 가용병력, 병력 현황, 전국 부대, 실시간 부대 현황
- 특정 부대명·부대번호·지역·군사시설
- 국방부 또는 각 군이 제작·인증·보증했다는 인상을 주는 문구
- 실제 제공하지 않는 대안 날짜 추천, 초대코드 전용, 익명 집계 등 미구현 기능

## App Store 키워드

```text
연가,외박,출타,복무,공유달력,잔여휴가,정기외박,위로휴가,청원휴가
```

## 출시 후 검토

4~6주 단위로 검색 노출과 전환을 확인하되, 다운로드를 늘리기 위해 공식성이나 보안 수준을 과장하지 않습니다. 기능과 데이터 처리 방식이 바뀌면 키워드보다 스토어 설명·개인정보 라벨의 정합성을 먼저 갱신합니다.
